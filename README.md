## Building the Android APK

Push to `main` (or run the **Build Android APK** workflow from the Actions tab).
When it finishes, download `finance-tracker-apk` from the run's **Artifacts**
section, unzip it, and copy `app-release.apk` to your phone.

Locally: `flutter pub get && flutter build apk --release`
→ `build/app/outputs/flutter-apk/app-release.apk`
